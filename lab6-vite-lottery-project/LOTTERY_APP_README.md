# React Lottery App

Застосунок лотереї створений на React + TypeScript з використанням Vite.

## Можливості

- ✅ Реєстрація учасників з валідацією полів
- ✅ Валідація форми в реальному часі
- ✅ Автоматичне форматування номера телефону `(___) ___-____`
- ✅ Date picker для вибору дати народження
- ✅ Перевірка що дата народження не в майбутньому
- ✅ Випадковий вибір переможців (максимум 3)
- ✅ Можливість видалення переможців
- ✅ Таблиця всіх зареєстрованих учасників

## Встановлення та запуск

### 1. Встановіть залежності:

```bash
npm install
```

Якщо Bootstrap не встановлено, виконайте:

```bash
npm install bootstrap
```

### 2. Запустіть проєкт:

```bash
npm run dev
```

### 3. Відкрийте в браузері:

```
http://localhost:5173
```

## Валідація полів

### Name (Ім'я)

- Обов'язкове поле
- Показує зелену рамку + галочку при валідному значенні

### Date of Birth (Дата народження)

- Обов'язкове поле
- Формат: yyyy-mm-dd
- Не може бути в майбутньому
- Використовує нативний HTML5 date picker

### Email (Електронна пошта)

- Обов'язкове поле
- Перевірка формату email за регулярним виразом
- Показує зелену рамку + галочку при валідному значенні

### Phone number (Номер телефону)

- Обов'язкове поле
- Автоматичне форматування: `(123) 456-7890`
- Перевірка формату за регулярним виразом
- Показує зелену рамку + галочку при валідному значенні

## Використання

1. **Реєстрація учасника:**

   - Заповніть всі поля форми
   - Поля валідуються автоматично після втрати фокусу
   - Натисніть кнопку "Save"
   - Форма очищується після успішного додавання

2. **Вибір переможця:**

   - Натисніть кнопку "New winner"
   - Випадковий учасник додається до блоку переможців
   - Максимум можна вибрати 3 переможців

3. **Видалення переможця:**
   - Натисніть "×" біля імені переможця в блоці переможців
